# 会发电的逆重引擎-continue

基于创意工坊 mod「会发电的逆重引擎」（作者 xiao_yan，[工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3530387840)）重做的个人版本。沿用原 mod 的预览图，packageId 在原 ID 后追加 .continue 后缀；两者可共存但功能重叠，请勿同时启用。

## 功能

逆重引擎获得基础发电量（默认 1000 W），并可通过填入**逆重板**提升发电量（默认每单位 +20 W），燃料上限默认 10000。燃料为投资模型：填入后不消耗，发电量随存量即时变化。

## 相对原版的改进

| 项 | 原 mod | 本版 |
|------|------|------|
| 自动加注 | 默认 30% 阈值，燃料条停在约三分之一处不再上涨 | 阈值 100%（原版飞船燃料罐的做法），殖民者持续加到目标量 |
| 目标燃料量 | 不支持 | 引擎上提供「设置目标燃料量」按钮 |
| 燃料 | 玻璃钢 | 玻璃钢（与原版一致） |
| 上限修改 | 需保存并重启游戏 | 即时生效（运行时改写 Def） |

## 设置

基础发电量（0–5000 W）、每单位燃料发电量（1–100 W）、燃料上限（100–20000）三项全部即时生效；「恢复默认值」一键还原（1000 / 20 / 10000）。界面内置简体中文与英文双语。

## 开发

```bash
dotnet build
```

产物组装到 `publish/`（About / Patches / 1.7\Assemblies / 预览图），建议目录联接到游戏 Mods 目录。目标 RimWorld 1.7，需要 Odyssey DLC（逆重引擎本体）。
